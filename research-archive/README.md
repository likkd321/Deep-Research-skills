# research-archive — 历史调研中间产物

> **非当次调研不要读这个目录。** 这里的文件只为复现与追溯保留，
> 内容体量大（单个脚本常有 700+ 行），读进主线程纯属浪费 token。

## 结构

```
research-archive/
  <调研标题>-<YYYY-MM-DD>/     每次调研一个目录
    build_*.py                 子 agent 生成 JSON 的构建脚本
    *.py / *.txt / *.json      其它中间产物
```

## 为什么保留构建脚本

子 agent 的典型工作方式是：先检索，再写一个 `build_xxx.py` 把结果拼成 JSON，最后执行它。
如果 agent 在"检索完但还没执行脚本"时被限额或超时打断，**重跑这个脚本就能零成本拿回全部结果**，
不必重新检索。2026-09-18 那次调研 6 个 agent 全部被会话限额打断，靠这个机制救回了 4 个。

因此：agent 异常中断时，先去 scratchpad 和本目录找 `build_*.py`，再考虑重跑。

### 补充Items
- Steam 平台政策与上架合规: 联机游戏上架 Steam 的要求。包括 Steam Networking 仅限 Steam 玩家（非Steam玩家无法联机）、Steam Deck 兼容、玩家 IP 暴露与隐私、AppID 测试与 Playtest 联机测试流程，以及 Steam 开发者 US$100 上架费。
- GodotSteam 的 GDExtension 与 Godot 4.4–4.6 版本兼容矩阵: 把已有 item2 拆细。覆盖 GodotSteam 与 SteamMultiplayerPeer（expressobits 版和 godotsteam/multiplayerpeer 官方版）的差异；有无 lobby 依赖；不支持 channels 和 mesh peers；`create_host` 静默失败等已知 bug（forum 137023）。
- Godot 官方 ENet / WebRTC / WebSocket 对比与 Steam 无关的备选: 把 ENet 对比作为基线。ENet 靠 UDP，家用路由器常拦截入站，需要端口转发或中继，这直接说明为什么要用 SDR。
- 开源参考实现 / 模板: 如 cooties（Godot + Steam Networking Sockets，权威服务器式 P2P，2026年1月仍有提交）、expressobits 示例、Last on Land 的 Steam lobby devlog。这些可作 Claude 生成代码的"范本"，也能核对 API 用法。
- 2025–2026 新近 Godot 联机商业作品复盘: 如 80.lv 报道的"Godot 4.6 + C# 上线联机游戏"团队复盘（待核实其架构和是否2D）。同时扫描 2024–2026 年 Godot 联机 Steam 新作。
- 房主离线检测与断线重连/重进: 单独拿出来，因为这是"不换主"档的基础。涉及 `server_disconnected` 信号、`Steam.getLobbyOwner`、Lobby 房主转移事件、中途加入（late join）的状态同步，以及断线重连后的状态恢复。
- Godot 版本升级迁移风险: 如 Godot 4.x 升级对网络 API 的破坏性改动、GDExtension 与引擎版本绑定、Steamworks SDK 升级。可并入 item16，也可独立。
- C# 与 GDScript 在联机下的取舍: 80.lv 案例用 C#。从 Claude 能力、性能、GodotSteam 的 C# 绑定（如 Facepunch.Steamworks 等）角度比较，会影响 Claude 把握度。
- Claude Code/AI 工作流实践: 如 Godot MCP、Ziva 之类的 AI 辅助 Godot 工具，以及用 Claude 写自动化联机测试（多实例本地回环、网络延迟/丢包模拟）。要点是如何用工具弥补 Claude 无法真机联调的短板。
- 联机测试与调试方法: 多实例本地测试、`tc`/Clumsy 之类的丢包延迟模拟、Steam 两账号测试，以及 desync 日志。这决定个人开发者能否验证"全球玩家"场景。
- 全球区域延迟与中国大陆连通性实测: 从 item1 单独拆出。内容包括 SDR POP 分布、跨洲延迟，以及大陆玩家连 Steam 中继的实际体验（待核实，可能需 Steam 社区/Reddit 反馈）。
- 玩家增长与匹配池冷启动策略: 小众联机游戏容易没人玩。可用 Steam Playtest、Demo、好友邀请与"Join Game"、跨平台房间，以及 Remote Play Together 作为低人数兜底（待核实适用性）。

### 推荐补充字段
- steam_only_restriction: 是否限定 Steam 玩家，以及对销售渠道（如 itch.io、Epic）和外部分发的影响。
- godot_version_compat: 支持的 Godot 版本区间、最后更新时间、官方是否承诺 4.x 跟进。
- last_commit_date / maintainer_count: 量化维护活跃度，用来判断 bus factor。
- nat_traversal_and_relay_behavior: 是否经中继、中继带宽费用谁付、直连成功率。
- late_join_and_reconnect_support: 中途加入与断线重连支持度，也是不换主档的关键。
- test_and_debug_tooling: 能否本地多开测试、延迟模拟，以及对 Claude 自测闭环的友好度。
- claude_training_data_signal: 该库在 GitHub/文档中的公开代码量与 API 稳定度，用来估算 Claude 出错概率。
- common_claude_errors: Claude 在该库上的典型错误，如 Godot 3 与 4 API 混用、RPC 注解错误、authority 设置错误。
- reference_implementations: 可抄的开源范例链接。
- steam_policy_compliance: 上架与隐私政策要点。
- estimated_dev_weeks_solo: 个人开发者借助 Claude 的粗略工期。
- scenario_matrix_verdict: 把24格的"可行/勉强/不建议"结论逐格标注，并附置信度。
- evidence_date: 证据日期与是否过期（2023年以前的算旧证据）。
- fallback_plan: 方案失败时的降级路径，如换主退化为"房主走了则结束局"。
